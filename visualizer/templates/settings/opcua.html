Сервер
Тот же флаг, что кнопки «Запустить/Остановить» в блоке состояния: сохраняется в конфиге и применяется процессом в течение ~2 секунд.
Если выключено, python run_kvt.py start и --service all пропустят процесс OPC UA. Ручной запуск python run_kvt.py start --service opcua всё равно доступен.

Экспортируемые поля
Безопасность
Текущий runtime реализует только anonymous read-only; certificate/user-password сохранены в конфиге для следующего ужесточения безопасности.
Historical Access (архивные данные)
HistoryRead отдаёт архивные значения температуры и влажности из хранилища Archive Manager по датчику и диапазону времени. Требует запущенной подсистемы Archive Manager.

Изменения выбора датчиков и полей перечитываются сервисом автоматически; смена host/port/security может потребовать перезапуска `python run_kvt.py restart --service opcua`.
