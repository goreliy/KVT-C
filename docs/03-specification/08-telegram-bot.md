# 8. Подсистема 6: Telegram Bot

> ⚠️ **СОСТОЯНИЕ: НЕ РЕАЛИЗОВАНО.** Раздел описывает планируемую подсистему. В коде нет
> пакета `telegram_bot/`, конфигурации `data/config/telegram_config.json`, а зависимости
> `python-telegram-bot` и `matplotlib` не входят в `requirements.txt`. Сервис `telegram`
> отсутствует в `run_kvt.py`. Уведомления в Telegram и email в текущей версии не работают.
> Сводка состояния подсистем — в [индексе документации](../README.md).

## 8.1 Функциональные требования

- Интерактивный Telegram-бот для получения данных по запросу
- Отправка графиков температуры/влажности за выбранный период
- Мгновенные уведомления при превышениях границ и тревогах
- Регулярные отчёты по настраиваемому расписанию
- Настройка регулярности отправки отчётов (ежечасно / ежедневно / еженедельно / ежемесячно)
- Поддержка нескольких чатов/пользователей

## 8.2 Команды бота

| Команда | Описание |
|---------|----------|
| /start | Регистрация чата, приветствие |
| /status | Текущие значения всех датчиков |
| /sensor {id\|name} | Текущие значения конкретного датчика |
| /chart {id\|name} [period] | График датчика (period: 1h, 6h, 24h, 7d, 30d) |
| /violations [period] | Список превышений за период |
| /report | Сформировать и отправить отчёт сейчас |
| /journal [period] | Сводка температур (min/max/avg) за период |
| /schedule | Показать текущее расписание отчётов |
| /schedule {hourly\|daily\|weekly\|monthly} {on\|off} | Включить/выключить тип отчёта |
| /help | Список доступных команд |
| /mute {minutes} | Приостановить уведомления на N минут |
| /unmute | Возобновить уведомления |

## 8.3 Формат уведомлений

### 8.3.1 Уведомление о превышении

```
⚠️ ПРЕВЫШЕНИЕ: ХРАН. № 1
Параметр: Температура
Значение: 26.1°C (порог: 25.0°C)
Тип: warning_high
Время: 14:22:10 13.01.2026
```

### 8.3.2 Уведомление о завершении превышения

```
✅ НОРМА: ХРАН. № 1
Параметр: Температура
Значение: 24.8°C
Длительность превышения: 13 мин 35 сек
Пиковое значение: 27.3°C
```

### 8.3.3 Уведомление о тревоге

```
🚨 ТРЕВОГА: ХРАН. № 1
Параметр: Температура
Значение: 30.2°C (порог: 25.0°C, alarm: +5.0°C)
Требуется квитирование!
```

## 8.4 Формат регулярного отчёта

Отчёт включает:

1. Сводную таблицу по всем датчикам (текущие значения, статусы)
2. Диапазоны температур/влажности за период (min / max / avg)
3. Количество и длительность превышений за период
4. Графики температуры и влажности (изображения)

Пример текстовой части:

```
📊 ЕЖЕДНЕВНЫЙ ОТЧЁТ КВТ
Период: 12.01.2026 08:00 — 13.01.2026 08:00

📍 ХРАН. № 1
  Температура: 21.3 .. 25.1°C (avg 23.2°C)
  Влажность: 40.0 .. 52.3% (avg 45.8%)
  Превышений: 2 (общая длительность 28 мин)

📍 ХРАН. № 3
  Температура: 3.1 .. 7.8°C (avg 5.2°C)
  Влажность: 35.2 .. 62.1% (avg 48.7%)
  Превышений: 0

Всего превышений за период: 2
```

После текста отправляются графики (изображения PNG).

## 8.5 Генерация графиков

Бот генерирует графики с помощью matplotlib:

- Линейный график температуры и влажности за период
- Отображение границ (warning/alarm) горизонтальными линиями
- Подсветка зон превышений
- Поддержка периодов: 1 час, 6 часов, 24 часа, 7 дней, 30 дней
- Формат вывода: PNG изображение

## 8.6 Планировщик отчётов

Планировщик на базе APScheduler поддерживает:

| Тип | Описание | Настройки |
|-----|----------|-----------|
| hourly | Каждый час | minute — минута отправки (0-59) |
| daily | Ежедневно | time — время отправки (HH:MM) |
| weekly | Еженедельно | day_of_week + time |
| monthly | Ежемесячно | day_of_month + time |

Каждый тип отчёта можно включить/выключить независимо. Расписание настраивается через:
- Файл `notifications.json` (раздел `telegram.reports.schedule`)
- Команду бота `/schedule`
- Веб-интерфейс: `/settings/reports`
