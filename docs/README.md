# Документация КВТ-С

Система мониторинга температуры и влажности на оборудовании **ИСО «Орион» (Болид)**:
датчики С2000-ВТ → ДПЛС/С2000-КДЛ → С2000-ПП → Modbus RTU (COM или С2000-Ethernet) → КВТ-С.

Общее описание системы, установка и эксплуатация — в [корневом README](../README.md).

## Соглашения по документации

- **Язык:** документация, интерфейс и комментарии — на русском; идентификаторы в коде — на английском.
- **Нумерация:** внутри спецификации сохранена сплошная нумерация разделов (§1–§15); номера
  подразделов (`3.2.1`, `5.11` и т. п.) стабильны — на них ссылаются другие документы и код-ревью.
- **Уровень заголовка** соответствует глубине номера: `# 3.` → `## 3.1` → `### 3.2.1` → `#### 3.2.2.1`.
- **Требование → дизайн → задача:** требования нумеруются (`Требование N`, критерий `N.M`),
  задачи ссылаются на них через `_Requirements: N.M_`.
- Если функция описана в спецификации, но не реализована — это помечается явно (см. таблицу
  состояния выше). Документация не должна утверждать наличие того, чего нет в коде.
