# КВТ-С — система мониторинга температуры и влажности

**КВТ** (комплект контроля температуры и влажности) — система непрерывного мониторинга
микроклимата на базе адресных датчиков **С2000-ВТ** производства ЗАО НВП «Болид» (ИСО «Орион»),
опрашиваемых по **Modbus RTU** через преобразователь протокола **С2000-ПП**.

## Цепочка сбора данных

```
С2000-ВТ (датчики) → ДПЛС → С2000-КДЛ → RS-485 «Орион» → С2000-ПП → Modbus RTU → КВТ-С
                                                                        │
                                        ┌───────────────────────────────┴──────────────┐
                                        │ COM-порт (USB-RS485)   или   С2000-Ethernet  │
                                        └──────────────────────────────────────────────┘
```

Приборы Болид настраиваются фирменной утилитой **UProg**; КВТ-С только читает готовые данные
из С2000-ПП и не конфигурирует оборудование.

## Назначение

- Автоматический циклический опрос датчиков С2000-ВТ / С2000-ВТИ через С2000-ПП по Modbus RTU
  (COM-порт или Ethernet), с независимыми линиями опроса.
- Визуализация в реальном времени: веб-мнемосхема, дерево датчиков, интерактивные планы помещений.
- Архивирование с компрессией (схлопывание одинаковых последовательных показаний) и ретенцией.
- Журналы: события, температуры, превышения границ — с квитированием.
- **Журнал учёта (складская отчётность)** — электронный аналог бумажного журнала: суточные
  min/max/avg по выбранным датчикам с ежедневной подписью оператора, пакетной подписью выходных
  и праздников и печатным листом для аудита.
- Передача данных во внешние системы: **OPC UA** (для SCADA/АСУ ТП) и **MQTT** (двунаправленно).
- Перенос настроек между установками через полный конфигурационный ZIP-архив.

## Целевые пользователи

- Операторы и кладовщики, контролирующие микроклимат складов, производственных и лабораторных
  помещений, холодильных камер.
- Инженеры АСУ ТП, интегрирующие данные в SCADA через OPC UA или MQTT.
- Служба качества/аудита — по журналу учёта с подписями.

## Развёртывание

Система — коммерческий продукт и ставится на любой ПК или ARM-контроллер под Linux, где есть
Python и необходимые библиотеки. Запуск — единой точкой `run_kvt.py`. Целевые платформы:
x86_64 и ARM v7 (например, контроллер ИнСАТ M3000-T).

Свой сетевой адрес система определяет автоматически (без жёстко прописанного петлевого адреса),
поэтому корректно работает при смене IP и на любом хосте.

- Идентификаторы в коде (переменные, функции, классы) — **на английском**.

## Состояние функций

Реализовано: опрос (COM/Ethernet), визуализация, архив, журналы, журнал учёта, OPC UA, MQTT,
перенос конфигурации.

Описано в спецификации, но **не реализовано**: Telegram-бот, email-уведомления, генератор отчётов
(PDF/HTML/CSV по расписанию), Docker-контейнеризация, PostgreSQL-хранилище архива,
OPC UA Historical Access. Актуальная сводка — в [индексе документации](../README.md).
